**AI Inbox Cleaner** is a privacy-first Chrome extension that helps you organize and clean your Gmail inbox using intelligent AI-powered categorization.

Instead of manually searching through thousands of emails, AI Inbox Cleaner automatically identifies newsletters, promotions, social notifications, and clutter, allowing you to review recommendations before taking any action.

# 🚀 How It Works

```text
Connect Gmail
      │
      ▼
AI scans your inbox
      │
      ▼
Review recommendations
      │
      ▼
Clean with one click
```

The extension never performs destructive actions automatically. Every recommendation is presented to the user for approval.

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/ai-inbox-cleaner.git
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build production extension

```bash
npm run build
```

# 🔑 Permissions

AI Inbox Cleaner requests only the permissions required to organize your Gmail.

- Gmail Read Access
- Gmail Modify Access
- Google OAuth Authentication

These permissions are used solely to provide inbox organization features.
